# Vue.js Learning Journey 🚀

> Structured path to master Vue.js development through practical examples and projects

## 🎯 Purpose
This repository documents a complete Vue.js learning path, featuring:
- Progressive learning from fundamentals tadvanced patter
- Hands-on projects with increasing complexity
- Real-world concepts like authenticatn, routing, a state management
- Modern practices using CompositionPI and Vue osystem tools

## 📂 Repository Structure
```text
vue-js-journey/
├── gs-*/             # Getting Started fundamentals
├── basics-*/         # Core Vue concepts (data binding, events, computed properties)
├── lists-cond-*/     # Conditional rendering & list management
├── prj-monster-*/    # Monster battle game project
├── behind-scenes-*/  # Vue internals and reactivity system
├── cmp-*/            # Component architecture (intro/communication/advanced)
├── vue-cli-*/        # Project scaffolding and tooling
├── forms-*/          # Form handling and validation
├── http-*/           # API communication and error handling
├── routing-*/        # Client-side routing with Vue Router
├── vuex-*/           # State management patterns
├── Main Project/     # Capstone project combining all concepts
├── auth-*/           # Authentication flow implementation
├── composition-*/    # Composition API patterns
└── reuse-*/          # Code reuse strategies (mixins/composables)
```

## 🧭 Learning Flow
1. **Fundamentals First**
   ```
   gs → basics → lists-cond → prj-monster
   ```
2. **Deep Understanding**
   ```
   behind-scenes → cmp-intro → vue-cli
   ```
3. **Component Mastery**
   ```
   cmp-communication → cmp-adv → forms
   ```
4. **Real-World Patterns**
   ```
   http → routing → vuex
   ```
5. **Advanced Concepts**
   ```
   composition → reuse → auth
   ```
6. **Final Challenge**
   ```
   Main Project (Capstone)
   ```

## 🛠️ Installation
```bash
git clone https://github.com/yourusername/vue-js-journey.git
cd vue-js-journey
npm install # in individual project folders
```

## 💻 Usage Recommendations
1. Follow numerical order within each category (e.g., `basics-01` before `basics-02`)
2. Each folder contains self-contained examples:
   ```bash
   cd basics-02-first-app && npm run dev
   ```
3. Project folders include complete implementations:
   ```bash
   cd Main-Project && npm run build
   ```
